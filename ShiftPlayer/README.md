# Shift Player

Видеоплеер для Android TV, который **смещает изображение по вертикали без масштабирования**.
Картинка не пересчитывается и не растягивается — она просто рисуется в другом месте экрана,
чтобы чёрная полоса оказалась только сверху или только снизу.

Сделан под TCL 98" RM7L (Google TV), но работает на любом Android 5.0+.

---

## Как собрать APK

### Вариант А — GitHub Actions (ничего ставить не нужно)

1. Создайте на GitHub новый **приватный** репозиторий.
2. Загрузите туда содержимое этой папки (кнопка *Add file → Upload files*,
   можно перетащить все файлы и папки сразу).
3. Вкладка **Actions** → workflow *Build APK* запустится сам после загрузки.
   Если не запустился — откройте его и нажмите *Run workflow*.
4. Через 3–5 минут внизу страницы сборки появится артефакт **shift-player-apk**.
   Скачайте — внутри `app-debug.apk`.

### Вариант Б — Android Studio

Открыть папку как проект → *Build → Build Bundle(s)/APK(s) → Build APK(s)*.
Gradle wrapper Studio создаст сам.

## Как установить на телевизор

1. На ТВ поставьте **Downloader** (by AFTVnews) или **Send Files to TV** из Google Play.
2. Залейте APK на телевизор и откройте его — система предложит установить.
   Понадобится разрешить установку из неизвестных источников.

Через компьютер по ADB:

```
adb connect <IP-телевизора>:5555
adb install -r app-debug.apk
```

Отладка по сети включается в *Настройки → Система → О системе* (7 раз по «Сборка»),
затем *Для разработчиков → Отладка по сети*.

## Управление с пульта

| Кнопка | Действие |
|---|---|
| **Вверх / Вниз** | сдвинуть картинку (шаг 4 px, при удержании — 24 px) |
| **1** | прижать картинку к верху экрана (полоса только снизу) |
| **2** | прижать картинку к низу экрана (полоса только сверху) |
| **0** или **Menu** | сбросить сдвиг в центр |
| **OK** | пауза / воспроизведение |
| **Влево / Вправо** | перемотка ±10 секунд |

Каналы +/− дублируют сдвиг, если на пульте нет удобных стрелок.

Значение сдвига **сохраняется отдельно для каждого соотношения сторон**.
Настроили один раз для 2.35:1 — все следующие широкоформатные фильмы
откроются уже сдвинутыми. Для 16:9 будет своё значение.

## Как открывать торрент-фильмы

Плеер регистрируется как обработчик видео. В TorrServe, LibreTorrent,
файловом менеджере или браузере выбирайте файл → **«Открыть с помощью» → Shift Player**.
Можно поставить галочку «всегда».

Плеер также запускается с рабочего стола — тогда он сразу откроет системный
выбор файла.

Поддержка: MKV, MP4, AVI, TS, M2TS, MOV, WebM, HLS (m3u8), DASH.

## Про предел сдвига

Сдвиг «бесплатен» только в пределах чёрной полосы. На индикаторе показан предел:

- фильм **2.35:1** на 4K-экране → полоса ≈ 263 px сверху и снизу,
  значит можно сдвинуть на 263 px и получить одну полосу в 526 px;
- фильм **1.85:1** → полоса ≈ 93 px;
- контент **16:9** → полос нет, предел 0.

Двигать дальше предела плеер позволяет, но тогда край картинки уезжает за экран —
в индикаторе загорится надпись **ОБРЕЗКА**. Это не баг, это физика: пикселям
некуда деваться.

## Настройка под себя

**Шаг сдвига** — `PlayerActivity.kt`, метод `onKeyDown`:

```kotlin
val step = if (event.repeatCount > 6) 24f else 4f
```

**Время показа индикатора** — там же, `showHud()`, значение `2000L` мс.

**Перемотка** — `seekBy(10_000L)`, миллисекунды.

**Если в режиме обрезки картинка ведёт себя странно** (не обрезается, а мигает) —
в `res/layout/activity_player.xml` замените

```xml
app:surface_type="surface_view"
```

на

```xml
app:surface_type="texture_view"
```

TextureView обрезается корректно всегда, но на 4K-контенте даёт большую нагрузку
и может потерять HDR. В пределах чёрной полосы обрезка не нужна вообще,
поэтому по умолчанию стоит SurfaceView.
